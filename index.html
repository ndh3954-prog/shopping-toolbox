API 키 설정

사용할 모델사의 API 키를 입력하세요. 키는 이 브라우저의 localStorage에만 저장되고, 생성 시 해당 모델사 서버로만 직접 전송됩니다.

Figma → 설정 → Personal access tokens에서 발급. 읽기 권한만 있으면 됩니다.
· 이 파일을 더블클릭해서 여신 경우, 브라우저 보안 정책 때문에 API 호출이 막힐 수 있습니다.
· 안 되면 이 파일이 있는 폴더에서 간단한 로컬 서버로 열어보세요. (예: 터미널에서 python -m http.server 실행 후 localhost 접속)
